# Anjo-Core : GenAI-Driven Autonomous Testing Framework

Anjo-Core is a completely free, open-source validation and automated software testing framework designed for modern, GenAI-driven development environments. 

## Vision
In the era of Generative AI, code is written faster than it can be tested. Anjo-Core provides a zero-trust audit layer and automated E2E testing to ensure that AI-generated deliverables meet strict enterprise quality standards without the overhead of manual QA.

## Core Features (Free to Use)
- **Automated Test Generation**: Dynamically parses functional requirements to generate robust test suites using advanced LLM integration.
- **Zero-Trust CI/CD Validation**: Seamlessly integrates into your existing pipelines (GitHub Actions, GitLab CI) to prevent regressions.
- **Deep Traceability**: Provides comprehensive audit logs and dependency graphs for all software components and AI-generated outputs.
